Delete branch: confirm, then watch it happen

The delete popup no longer closes the moment you confirm. It stays open and switches to the step checklist the "Delete branch & worktree" dialog already uses (StepRow, OutcomeBadge), so a slow push to the remote is visible and a partial result is shown in place.

The checkbox appears only when the upstream has the same name and its tracking ref exists. It starts unticked; ticking it shows the remote preview and turns the button into "Delete both".

Remote first, leased to the tracking ref's tip, then the forced local delete. Unticked, the list has two rows: delete local, refresh.

On success the dialog closes itself shortly after the last row is checked. Closed mid-run, the delete keeps going and a failure arrives as a notification.

A failed remote step deletes nothing: its row turns red and the title reads "Nothing was deleted". The rows that ran stay checked.
