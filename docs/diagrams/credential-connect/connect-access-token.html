What the token needs Suggestions, not requirements: choose what fits how you work. GitLane only needs access to the repositories you open here.
Fine-grained
Resource owner
The account or organization that owns the repositories you'll use. An organization may need an admin to approve the token.
Repository access
Any choice that includes those repositories. All repositories is simplest; selecting only some keeps the token narrower.
Permissions › Contents
Read and write if you want to push; Read only is enough to fetch and pull. Metadata: Read is added for you.
Classic
Scope
repo gives access to every repository your account can reach. Simpler, but broader than a fine-grained token.
Add workflow
If you push changes to .github/workflows.
Expiration
Your choice. When it expires, Git stops authenticating and GitLane asks for a new one.
